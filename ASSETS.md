# Bard Beats, Asset Plan

Date: November 19, 2026
Status: Draft. Grounded in ARCHITECTURE.md (Nov 19, 2026).

## How assets work in this app

- Image assets live in gfx/ as PNGs, indexed in gfx/sprites.t3s, compiled at build time by tex3ds into romfs/gfx/sprites.t3x plus a generated C header build/sprites.h.
- Static assets (sprite sheets, instrument sample tables, default starter loops) live in romfs/ and are embedded into both .3dsx and .cia.
- Instrument sounds are original and IP-clean. Part procedural synthesis computed live, part pre-synthesized wavetables generated at build time by tools/gen_instruments.py. No external SoundFonts or ripped samples.
- The app boots straight into Loop 1 at 110 BPM. There is no title screen menu, so there is no title screen art asset.

## Instrument art (gfx/instruments/)

The rendered instrument view shows the active instrument on the top screen (400x240). One render per launch instrument, 8 total:

| Instrument | Track role | Sound technique |
| Tavern Kit | Drums | Wavetable (Bodhran Kick, Tavern Clap, Tambourine) |
| 8-Bit Kit | Drums | Procedural percussion noise |
| Upright Bass | Bass | Wavetable (Acoustic Bass) |
| Sub Bass | Bass | Procedural |
| Bard's Lute | Melody | Wavetable (Karplus-Strong string modeling) |
| Ocarina | Melody / Harmony | Procedural |
| Pulse Lead | Melody / Harmony | Procedural chiptune pulse |
| Minstrel Harp | Harmony / Chords | Wavetable |

Boot defaults: Tavern Kit on Drums, Upright Bass on Bass, Bard's Lute on Melody, Ocarina on Lead/Harmony. All renders are original art, bard and tavern flavored, generic fantasy only.

## UI art (gfx/ui/)

- Big tap-target buttons (play, record, undo, save, copy).
- Step cells for the 16-step grid.
- Spellbook tabs for the saved loop list.
- Small icons (BPM, vocal, track roles).
- Loop list cards are code-drawn (148x44 px each, showing loop name, BPM badge, and vocal icon), not image assets.

## Audio assets (romfs/audio/)

- Wavetables generated at build time by tools/gen_instruments.py: Lute, Harp, Acoustic Bass, Bodhran Kick, Tavern Clap, Tambourine. Karplus-Strong physical string modeling and modal drum synthesis, 16-bit mono, total under 512 KB in RomFS. Generated, no hand-made files.
- Procedural sounds computed live, no files: Ocarina, Chiptune Pulse, Sub Bass, Hurdy-Gurdy Drone, Percussion Noise.
- No external SoundFonts or ripped game samples, ever.

## Default content

- Default starter loops in romfs/, shipped with the app so it boots into a ready loop. Count and contents TBD once the sequencer runs.

## Out of scope for v1

- Title screen art (the app boots straight into a loop).
- External sample packs or SoundFonts.
- Custom user-imported samples.
